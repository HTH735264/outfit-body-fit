# 输出模板

## 模板 A：有测量数据（置信度高）

```markdown
## 比例判读

| 指标 | 你的值 | 判读 |
|---|---|---|
| 肩臀比 | 0.95 | 肩线比胯线窄，视觉重量偏下 |
| 腰臀比 | 0.77 | 腰存在感中等，能造腰但不用硬勒 |
| 胸腰差 | 15cm | 上身起伏中等 |
| 腿长比 | 0.45 | 腿部占比略小，分割线要往上抬 |
| 头肩比 | 0.41（视觉估计） | 肩显窄，头在视觉上偏大 |

主视觉轴：**肩窄于胯**。先修这条，其他是局部。

## 三条处方（按影响排序）

1. **抬肩线** — 正肩剪裁 + 薄垫肩，领口用船领或方领。肩线到肩峰多一点，上半身的视觉体积立刻回来。别用厚垫肩，会变成假肩。
2. **把腰线往上抬 3–4cm** — 高腰 + 短上衣，上下装颜色接近。腿长比 0.45 靠这个补，不要靠高跟鞋。
3. **下装收窄** — 直筒或微锥、九分、深一档。避开大摆伞裙和胯部贴袋，那会把胯推到全身最宽处。

## 两套搭配

**通勤**
- 上：米白正肩薄垫肩西装，肩线落在肩峰外 0.5cm 内
- 内：同色系方领细针织
- 下：深灰直筒九分西裤，高腰
- 鞋：与西裤同色系尖头平底或低跟
- 为什么：正肩补肩宽、方领把视线收到中间、上下接近同色抬腰线、九分露踝再加一截腿

**周末**
- 上：船领短款针织，浅色
- 外：短款直筒夹克，长度到胯上沿
- 下：中蓝直筒九分丹宁，高腰
- 鞋：小白鞋
- 为什么：船领横向打开肩线，短上衣把腰线抬高，直筒丹宁不给胯加体积

## 雷区

- **插肩袖 / 落肩卫衣** — 同时削肩宽和压腰线，两个问题一起放大
- **大摆伞裙 + 短上衣** — 胯变成全身最宽处
- **中筒靴** — 卡在小腿最粗处，腿被切成两段

## 置信度与待补

数据完整度：**高**（五个核心数齐全，四项实测）。

判断置信度：**中到高**——规则是经验性视觉判断，不是测量学结论；且头肩比是视觉估计，不计入实测。

想再升一级：补头宽（把 0.41 变成实数）、补肩峰高（算躯干比，决定上装长度）。
```

## 模板 B：只有照片（置信度低）

短一半，结构保留，开头必须声明：

```markdown
> **照片影响等级**：中（仰拍 + 高腰阔腿裤 + 短上衣 → 腰线和腿长都被抬高，读出来偏乐观）
> **不可读**：腰臀比（上装宽松）、头肩比（手机挡脸）
> 以下判断的是照片中呈现的比例，不是原始骨架。补上肩宽、臀宽、腰围、臀围、身高，幅度会更准。

轮廓走向偏上窄下宽：肩线看起来比胯线窄，腰最细处位置偏高，视觉重量更集中在下半身。

**三个动作**
1. 上装加肩结构（正肩、船领），下装收窄直筒 —— 把重量从胯往上挪
2. 高腰 + 短上衣 + 上下接近同色 —— 抬高分割线
3. 领口开大 —— 肩显宽，头就不会显大

**避开**：插肩袖、大摆裙、中筒靴。

**两套**：（同上结构，各三到四件，一句话说为什么）

数据完整度：**低**（只有照片）。判断置信度：**低**——这张图如果是宽松上衣或俯拍，肩胯关系可能完全相反。
```

## 禁止写法对照

| 不要写 | 改成 |
|---|---|
| 你是标准的梨形身材 | 肩线比胯线窄，视觉重量偏下 |
| 你的腿比较短 | 腿部在整体分割里占比略小 |
| 这样穿能显瘦 10 斤 | 这样穿把重量从胯移到肩 |
| 建议你减到 XX 斤 | （不出现，见硬性边界） |
| 这个身材穿什么都难 | 这个比例的主视觉轴是 X，修这一条收益最大 |

## 三条硬规则

1. 先给方向再给清单，不要一上来列十个单品。
2. 每条处方必须带「为什么」，否则用户不知道下次怎么自己判断。
3. 处方不超过五条。超过五条等于没给。
