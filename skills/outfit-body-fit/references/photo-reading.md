# 照片判读

照片用于描述这张图里可见的穿着效果。衣服、姿势、距离与角度共同形成画面，不能据此反推出原始骨架或身体测量值。先看用户要判断整套效果、单件合身，还是寻找比例调整方向，只读与当前问题有关的部分。

## 一、能观察什么

| 内容 | 合适表述 |
|---|---|
| 可见衣服外轮廓 | “这张图里，上衣肩部外轮廓比下装胯部窄一些。” |
| 衣服分割线与下摆位置 | “裤腰把穿着分割线放在较高位置。” |
| 可见头肩外轮廓的对比 | “这张图里，发型外轮廓与衣服肩线的对比较明显。” |
| 当前姿势和遮挡 | “一侧手臂向前，可能影响这一侧肩线的呈现。” |
| 衣服合身迹象 | “扣间出现拉扯褶；建议比较胸前余量更合适的一件。” |
| 当前单品细节 | “肩缝明显越过可见肩部转折点；需结合落肩设计判断。” |

只描述当下姿势，不把单张照片写成“姿态习惯”或身体问题。衣服肩缝不等于肩峰点，裤腰不等于自然腰线，裤裆不等于会阴点。没有明确参照尺度时，不给衣服或身体的厘米估计。

## 二、不能从照片给出的数字

- 身高、体重、肩宽、臀宽、任何围度或厘米差。
- SHR、WHR、胸腰差、LBR、TBR、HSR 的测量值，包括“0.41（视觉估计）”之类小数。
- 被衣服遮住的自然腰线、身体轮廓、组织分布或骨骼长度。

只看得到衣服轮廓时，可以评价这件衣服呈现的形状，不把它记作身体数据。用户另给有效实测值时，数字指标独立计算；照片不可读只限制照片观察，不覆盖实测，也不替缺失测量补数。

## 三、按实际可见性判断可靠程度

先识别遮挡、透视和衣服影响，再决定哪些观察能支持当前建议。轻、中、重描述的是**本次观察受限程度**，不是照片真假鉴定。

| 程度 | 情况 | 处理 |
|---|---|---|
| 轻 | 与当前问题有关的衣服轮廓、接缝和分割基本可见 | 直接给观察与建议，必要时用一句话说明画面条件 |
| 中 | 遮挡、姿势或明显透视使某个相关部分不清楚 | 指明该观察“不可读”或“受限”，只用其余可见部分 |
| 重 | 当前问题所需的关键信息大多不可见，或用户确认图像为生成/比例改动素材 | 停止根据此图判断用户身体比例；仍可讨论衣服设计、搭配手法和参考风格 |

普通有跟鞋、同色穿着、手插口袋或商业模特图不自动触发某个等级。是否妨碍观察取决于当前要判断什么。

### 常见影响与处理

| 画面条件 | 可能受影响的内容 | 处理 |
|---|---|---|
| 高腰、短上衣、厚底或有跟鞋 | 分割线和鞋底高度改变可见上下比例 | 描述呈现效果，不反推自然腰线与腿长 |
| 宽松外套遮住腰胯 | 内部身体轮廓、自然腰线 | 这些内容不可读；外套轮廓、长度或搭配仍可评估 |
| 垫肩、泡泡袖、插肩、落肩 | 衣服肩部轮廓与真实肩宽的对应关系 | 不按袖型直接断定肩宽增减，比较具体肩线和面料 |
| 手机挡头、头部被裁 | 完整头肩外轮廓对比 | 该观察不可读，不据此给缩小头肩对比的处方 |
| 双脚被裁、半身、坐姿 | 整体上下分割与裤鞋衔接 | 整体观察受限；仍可看清晰入镜的领口、肩线或局部合身 |
| 扭转、手臂前伸、手插口袋 | 肩胯投影和左右对称性 | 端点不清楚就不判断方向，不把姿势效果记成身体特征 |
| 只给侧面 | 正面肩胯宽度关系 | 正面关系不可读；侧面拉扯与余量可单独评价 |
| 全深色、同色或光线暗 | 接缝和分割的可见性可能下降 | 只有看不清时才标受限，颜色本身不证明信息消失 |
| 近距离、明显俯仰拍或广角 | 各部位的相对投影 | 不断言“必然腿长/头大”，对受影响比较降低确信程度 |

### 疑似修图或生成

皮肤平滑、反射异常、背景弯曲或水印可以提示不确定性，单一迹象不能证明 AI 生成、使用了拉长工具或照片造假。可以说“这里的变形使比例观察不可靠”，不说“这张肯定修过”。若用户确认是生成图或改动比例的参考图，只分析衣服设计和视觉手法，不把图中人物比例套给用户。

商业模特图可以作风格或版型参考。没有用户身体数据时，不根据模特呈现断定用户穿上也有相同效果。

## 四、表达与建议要对得上

观察中注明“从这张图看”“看起来”或具体限制，并说明支持建议的可见信息。不可读部分不参与后面的个体处方；不要先声明腰线被遮住，后面又判断自然腰线偏高。

示例：

> 这张图中手机挡住了头部，外套也盖住腰线，因此头肩对比和自然腰线都不可读。可见的是外套肩部较柔和、下摆停在胯部附近。如果你希望肩部更有结构，可以用正肩外套作一次对比试穿。这里判断的是照片里呈现的穿着效果。

限制影响当前判断时说清即可；普通搭配点评不必先解释一整段测量风险。

## 五、需要补拍时

只请求当前问题真正需要的一张或一个角度，用户不愿补拍就使用已有可见信息：

- 需要整体分割：头脚完整入镜，镜头大致与胸部同高、保持水平，站远一些，避免近距离广角。
- 需要正面肩胯呈现：自然站立，手臂放松，避免明显扭转或遮挡；不要要求刻意矫正姿势。
- 需要单件合身：补相关部位正面或侧面，重点看接缝、拉扯、余量和活动情况。
- 背景简洁、光线均匀更易观察。普通日常衣服即可，不要求内衣照或暴露部位。

不要把“2×”当成长焦和可靠比例的保证；手机镜头与拍摄距离不同，优先解释站远和保持画面水平。

## 六、照片与数字不一致时

先确认数字字段、单位、量法和时点。有效测量用于计算，照片用于描述这套衣服的呈现，两者不必相同。若测量口径尚未确认，标“待确认”，不直接把数字当成最终结论。可提出服装或角度等可能因素，不凭画面断定原因。

> 你提供的肩宽与臀宽很接近，而这件上衣在照片里肩部轮廓更窄。数字反映测量关系，照片反映这套穿着；袖型、姿势或角度都可能参与其中。若你的目标是增加肩部结构，可以比较另一件正肩上衣。

不为迎合照片改测量值，也不以测量结果否定用户对穿着效果的感受。
