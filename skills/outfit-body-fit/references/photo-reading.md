# 照片判读

照片只用来判断**视觉比例印象**。它不是测量工具，而且经常已经被修过一轮。

## 一、能判断什么

| 能看 | 表述方式 |
|---|---|
| 整体轮廓走向（上宽下窄 / 上窄下宽 / 直筒 / 有腰） | 「轮廓走向偏上窄下宽，视觉重量更集中在下半身」 |
| 肩端点与胯最宽处的相对位置 | 「肩线看起来比胯线窄」 |
| 上下身分割线在哪 | 「腰最细处偏高，接近肋下」 |
| 头与肩的横向比 | 「头宽接近肩宽的一半，肩显窄」 |
| 姿态习惯 | 「有轻度含胸，肩端点前移」 |
| 已穿衣服的合身度 | 「这件外套肩线落在肩外 1–2cm」 |

## 二、不能判断什么

- 任何绝对围度、身高、体重
- 被衣服遮住的躯干形状（穿宽松上衣时完全看不到腰）
- 精确腿长（裤子的裆线位置会移动视觉裆点）
- 肩宽与臀宽的厘米差（只能判断方向，判断不了幅度）
- 肌肉 / 脂肪分布的具体情况

## 三、先判断照片被修过没有

这一步不能跳。照片里的比例经常已经被服装和拍摄改过，跳过它就会把加工结果当成骨架，而且读得很有说服力。

### 3.1 三类修正

**服装类**——被改的是腰线位置、肩宽、腿长比、下盘体积

| 信号 | 改了什么 |
|---|---|
| 高腰下装 | 腰线抬高，腿长比虚高 |
| 短款上衣 | 分割线上移 |
| 宽松上衣 / oversize 外套 | 腰线、肩宽、胸腰差全部失真 |
| 垫肩 / 泡泡袖 / 船领 | 肩宽被加 |
| 插肩 / 落肩 / 斜肩 | 肩宽被削 |
| 高跟鞋 / 厚底 | 腿长比虚高 |
| 深色紧身下装 | 下盘被收敛 |
| 阔腿 / 微喇 / 大摆 | 下盘被放大 |

**拍摄类**——被改的是腿长、头肩比、肩线朝向

| 信号 | 后果 |
|---|---|
| 仰拍（地平线低于膝） | 下半身被拉长 → 腿长、肩窄 |
| 俯拍 | 下半身被压缩 → 腿短、头大 |
| 广角近距离 | 画面中心放大、边缘拉伸 → 腿显长、头显大 |
| 镜面自拍 | 视角被持机高度支配，手臂和手机遮挡 |
| 踮脚 / 厚底鞋 | 腿长比失真 |
| 含胸 | 肩显窄 |
| 塌腰 | 腰线消失 |
| 单肩高 / 扭胯 | 左右不对称被误读成骨架问题 |
| 手插口袋 | 肩线后收，肩宽读窄 |

**图像类**——影响全部指标

| 信号 | 说明 |
|---|---|
| AI 生成水印 | 人体比例不来自任何真实测量，只能拆手法，不能判读身材 |
| 皮肤过度平滑、反射不自然 | 疑似生成或重度修图 |
| 腿线不自然、背景拉伸 | 拉长工具用过 |
| 商用 / 模特素材 | 本身就是挑选和修饰过的样本 |

### 3.2 信号 → 不可读

命中右侧信号时，对应指标**必须写「不可读」，不要猜一个值填上**：

| 信号 | 不可读的指标 |
|---|---|
| 宽松上衣 / 外套 | 腰臀比、腰线位置、胸腰差 |
| 手插口袋 | 肩宽（只能判方向，不能定幅度） |
| 手机挡脸 / 头部被裁 | 头肩比 |
| 双脚被裁 / 坐姿 / 半身 / 蹲姿 | 腿长比、躯干比 |
| 全身同色或全深色 | 腰线位置、上下分割 |
| 只给侧面 | 肩臀比、腰臀比 |

**这条只适用于照片通道。** 用户同时给了数字时，有数字的指标照常算，照片读不到不影响它——见 SKILL.md 第 0 步规则 4。

### 3.3 处置（按影响分级，不是一律报警）

普通照片几乎总会命中一两条，全都写成长篇声明会淹没结论。所以分三级：

| 等级 | 触发 | 处置 |
|---|---|---|
| 轻 | 只有常规穿着：有跟鞋、常规裤装、路边自然站姿 | 末尾一句话带过，不占篇幅 |
| 中 | 修正改变了关键指标：宽松外套遮腰、手插口袋、手机挡脸、双脚被裁、明显仰拍俯拍 | 该指标标「**不可读**」，其余照常 |
| 重 | 图像不可信：AI 生成、明显拉伸修图、商用精修模特图 | **停止比例判读**，只给版型与搭配建议 |

中、重两级才需要在输出开头写明命中条目。声明句固定用：「以下判断的是照片中呈现的比例，不是原始骨架」。

关键信息被抹掉的指标要写「不可读」，并说明补一张什么样的照片能读到。

### 3.4 话术示例

> 这张是电梯镜面自拍，手机挡住了头部，双脚也在画面外。按规则头肩比和腿长比不可读，我只对肩胯关系给方向。另外这条裙子是宽腰封加高腰，腰的位置是被抬高的，不代表你的自然腰线。以下判断的是照片中呈现的比例，不是原始骨架。

## 四、拍摄要求

满足越多，置信度越高。在补拍建议里也按这个顺序给：

1. 正面 + 侧面各一张
2. 镜头与胸同高，平视（不要俯拍仰拍）
3. 后退 3–4 米拍，或用 2× 长焦，避免广角
4. 双脚并拢自然站，不摆姿势、不含胸、不踮脚、不插口袋
5. 贴身衣物或运动装；不要穿宽松外套
6. 全身入镜，头和脚都不要被裁掉
7. 中性背景，光线均匀，不要逆光

用户只给一张、且穿宽松衣服时：照常判读，但置信度写「低」，并点出哪几条最可能不准。

## 五、表达纪律

**必须带不确定标记的词**：看起来、大约、偏、印象、可能、从这张图判断。

**禁止的写法**：

- 「你的肩宽约 38cm」——照片反推围度
- 「你是标准的梨形身材」——把标签当结论
- 「你的腿比较短」——把比例判读写成人身属性，应写「腿部在整体分割里占比偏小」
- 「这张图里腿很长，所以你腿长」——把修正当成骨架

**正确的写法**：

> 从这张正面图看，肩线比胯线窄一些，腰最细处位置偏高。如果你确实是这个走向，上装加肩结构、下装收窄会立刻改善上轻下重的感觉。这两个判断受拍摄角度影响，补一下肩宽和臀宽可以确认幅度。

## 六、照片与数字冲突时

以数字为准，并用一句话解释冲突，同时指出照片里哪个修正动作可能造成了偏差：

> 你说的肩宽和臀宽只差 1cm，但照片里肩看起来明显窄——大概率是这张照片含胸，或者上衣肩线偏内、又是落肩版型。我按数字算的均衡来给方案。

不要为了照顾照片而改数字结论，也不要因为数字否掉用户的自我感受。两个都摆出来，说明依据。
