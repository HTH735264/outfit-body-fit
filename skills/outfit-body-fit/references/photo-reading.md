# 照片判读

照片只用来判断**视觉比例印象**。它不是测量工具。

## 一、能判断什么

| 能看 | 表述方式 |
|---|---|
| 整体轮廓走向（上宽下窄 / 上窄下宽 / 直筒 / 有腰） | 「轮廓偏 A 型，重量在下半身」 |
| 肩端点与胯最宽处的相对位置 | 「肩线看起来比胯线窄」 |
| 上下身分割线在哪 | 「腰最细处偏高，接近肋下」 |
| 头与肩的横向比 | 「头宽接近肩宽的一半，肩显窄」 |
| 姿态习惯 | 「有轻度含胸，肩端点前移」 |
| 已穿衣服的合身度 | 「这件外套肩线落在肩外 1–2cm」 |

## 二、不能判断什么

- 任何绝对围度、身高、体重
- 被衣服遮住的躯干形状（穿宽松上衣时完全看不到腰）
- 精确腿长（裤子的裆线位置会移动视觉裆点）
- 肩宽与臀宽的厘米差（只能判断方向，判断不了幅度）
- 肌肉/脂肪分布的具体情况

## 三、误差来源（每一条都会让判读反向）

| 来源 | 后果 |
|---|---|
| 手机近距离广角 | 画面中心放大、边缘拉伸 → 腿显长、头显大 |
| 俯拍 | 下半身被压缩 → 腿短、头大 |
| 仰拍 | 下半身被拉长 → 腿长、肩窄 |
| 宽松上衣 | 腰线位置失真，肩宽看起来比实际宽 |
| 贴身高腰裤 | 腰线被抬高，腿显长 |
| 含胸 | 肩显窄 |
| 塌腰 | 腰线消失 |
| 单肩高 / 扭胯 | 左右不对称被误读成骨架问题 |
| 踮脚 / 穿厚底鞋 | 腿长比失真 |

## 四、拍摄要求

满足越多，置信度越高：

1. 正面 + 侧面各一张
2. 镜头与胸同高，平视（不要俯拍仰拍）
3. 后退 3–4 米拍，或用 2× 长焦，避免广角
4. 双脚并拢自然站，不摆姿势、不含胸、不踮脚
5. 贴身衣物或运动装；不要穿宽松外套
6. 全身入镜，脚不要被裁掉
7. 中性背景，光线均匀，不要逆光

用户只给一张、且穿宽松衣服时：照常判读，但把置信度写成「低」，并在结尾点出哪一条最可能不准。

## 五、表达纪律

**必须带不确定标记的词**：看起来、大约、偏、印象、可能、从这张图判断。

**禁止的写法**：
- 「你的肩宽约 38cm」——照片反推围度
- 「你是标准的梨形身材」——把标签当结论
- 「你的腿比较短」——把比例判读写成人身属性，应写「腿部在整体分割里占比偏小」

**正确的写法**：
> 从这张正面图看，肩线比胯线窄一些，腰最细处位置偏高。如果你确实是这个走向，上装加肩结构、下装收窄会立刻改善上轻下重的感觉。这两个判断受拍摄角度影响，补一下肩宽和臀宽可以确认幅度。

## 六、照片与数字冲突时

以数字为准，并用一句话解释冲突：

> 你说的肩宽和臀宽只差 1cm，但照片里肩看起来明显窄——大概率是这张照片含胸或者上衣肩线偏内，我按数字算的均衡来给方案。

不要为了照顾照片而改数字结论，也不要因为数字否掉用户的自我感受。两个都摆出来，说明依据。
