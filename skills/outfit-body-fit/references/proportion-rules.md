# 比例规则与版型处方

## 一、指标、算法与阈值

阈值是默认值，不是生理事实。骨架极端（很矮/很高、肩特别宽、臀特别窄）时，把阈值向"更接近均衡"方向松 0.02–0.03，并在输出里说一句校准了什么。

| 指标 | 算法 | 默认阈值 | 视觉后果 |
|---|---|---|---|
| 肩臀比 SHR | 肩宽 ÷ 臀宽 | ≥1.04 肩宽于胯<br>≤0.96 肩窄于胯<br>其余均衡 | 决定主视觉轴：重量在上半身还是下半身 |
| 腰臀比 WHR | 腰围 ÷ 臀围 | <0.75 腰线明确<br>0.75–0.85 中等<br>>0.85 腰线弱 | 腰在整体轮廓里有没有"存在感" |
| 胸腰差 | 胸围 − 腰围 | ≥18cm 有起伏<br>10–18cm 中等<br><10cm 平直 | 上身是曲线还是直线 |
| 腿长比 LBR | 会阴高 ÷ 身高 | <0.45 短<br>0.45–0.48 常规<br>>0.48 长 | 腿在整体分割里的占比 |
| 躯干比 TBR | (肩峰高 − 腰高) ÷ 身高 | 偏低=短躯干<br>偏高=长躯干 | 上装长度、腰线位置的选择空间 |
| 头肩比 HSR | 头宽 ÷ 肩宽 | >0.40 头显大肩显窄 | 领型与发型的横向量 |

### 测量口径（必须统一，否则比例全错）

- **肩宽**：左右肩峰点（肩骨最外端骨突）之间的直线距离。不是肩关节、不是衣服肩线、不是肩到肩的弧线。
- **臀宽**：臀部最丰满处两侧的水平直线距离，不是围度。
- **腰围**：躯干最细处一周，通常在肋骨下缘与髂嵴之间。自然呼气末测量，不吸肚子。
- **腰高**：腰围最细处所在水平面到地面。
- **会阴高**：耻骨联合下缘到地面（站直、双脚并拢）。
- **头宽**：两侧颞部最宽处直线距离。

口径不统一时，SHR 会偏 0.05 以上，判读直接反向。测量前先确认用户用的是哪一种，对不上就重来。

## 二、症状 → 处方表

每条格式：**观察到的比例特征 → 视觉目标 → 具体动作 → 反向操作（避开）**。

### 1. 肩窄于胯（SHR ≤ 0.96）

- 目标：抬高肩线、把视觉重量上移
- 上装：正肩剪裁、薄垫肩西装、船领、方领、一字领、育克横线、上身浅色或亮色或大图案
- 下装：深色、直筒、微锥、九分；避免大摆伞裙把胯推到最宽
- 反向：插肩袖、落肩、深 V 在上身形成收窄三角、包臀短裙、胯部大口袋
- 腰线：略高于自然腰，把上下分割线抬高
- 注意：加肩宽不等于加肩垫厚度。薄垫肩 + 正肩线就够，厚垫肩会变成假肩。

### 2. 肩宽于胯（SHR ≥ 1.04）

- 目标：弱化肩端点、下盘加体积
- 上装：插肩袖、落肩、斜肩、V 领、深 U 领、竖条、深色、无肩章无横条无垫肩
- 下装：A 字、阔腿、百褶、工装口袋、浅色、横向细节、中长裙
- 反向：泡泡袖、羊腿袖、船领、方领、横条纹、肩部荷叶边、短袖卡在肩端点
- 腰线：可略低，配合下装体积形成 A 型

### 3. 腰线弱（WHR > 0.85）

- 目标：要么造出腰，要么干脆不造
- 路线① 做结构：收腰剪裁、腰带、上下色块在腰处分界、塞衣角、高腰
- 路线② 顺直筒：H 型直线条 + 垂坠面料，靠纵向线条取胜，不硬勒
- 反向：紧身针织包住腰腹、低腰 + 短上衣露出腰腹最宽处、硬腰带勒出上下溢肉
- 判断：用户平时穿收腰舒服还是穿直筒舒服？舒服的那条路线才穿得住。

### 4. 腰线明确（WHR < 0.75）

- 自然腰线是资产，收腰单品加分
- 反向：宽松直筒把腰藏掉（除非用户主动想走中性路线）、上下都 oversize

### 5. 短躯干（TBR 偏高，肩到腰距离短）

- 上装短款、高腰下装，提高腰线
- V 领、开襟外套、纵向分割拉长
- 反向：宽腰封、长上衣盖过胯、高位宽腰带
- 注意：短躯干 + 腰线弱是常见组合，两个一起处理时优先"顺直筒"，别硬造腰。

### 6. 长躯干（TBR 偏低）

- 腰线下移：宽腰封、中长上衣、低腰
- 可用长外套、长马甲
- 反向：短上衣 + 低腰，会把躯干切得更长

### 7. 短腿（LBR < 0.45）

- 高腰、上下同色系（连体裤、同色套装）、短上衣、露踝、鞋裤同色
- 纵向延伸：裤中缝、竖条、长项链
- 反向：中筒靴卡在小腿最粗处、长上衣压胯、低腰裤、颜色在脚踝处截断
- 注意：鞋裤同色是这条里性价比最高的动作。

### 8. 长腿（LBR > 0.48）

- 可低腰、可长外套、可宽松长裤、可及踝长裙
- 反向：没必要强行高腰，会显得上身过短

### 9. 头显大、肩显窄（HSR > 0.40）

- 加肩宽（同第 1 条）、发型加横向体积、领口开大
- 反向：紧贴头皮的发型、高领 + 小圆领、尖领

### 10. 颈短

- V 领、大 U 领、开襟、低领、竖条
- 反向：高领 + 围巾 + choker 叠在一起

### 11. 胸大（胸腰差 ≥ 18cm 且胸围大）

- V 领、垂坠面料、收腰、单排扣
- 反向：高领、胸前大图案/口袋/荷叶边、硬挺 boxy 上衣、双排扣
- 注意：不是"藏胸"，是减少胸前的横向体积。

### 12. 胸小 / 上身平直（胸腰差 < 10cm）

- 胸前细节：抽褶、褶皱、口袋、层次、横条纹
- 高领可穿，是优势
- 反向：深 V 空荡、胸前完全无细节的薄针织

### 13. 小腿粗

- 及踝、九分、直筒、阔腿、靴筒过小腿最粗处
- 反向：中筒靴、紧身小腿裤、卡在最粗处的裙长

### 14. 大腿粗

- 直筒、阔腿、微喇、深色、硬挺面料（丹宁、西装呢）
- 反向：紧身浅色牛仔、包臀、薄弹力面料

### 15. 手臂粗

- 中袖、七分袖、落肩、宽松袖口
- 反向：紧身短袖卡在上臂最粗处、无袖

### 16. 胯宽（臀宽大但肩不窄）

- 深色下装、直筒、A 字但摆幅小、上装盖过胯最宽点
- 反向：胯部贴袋、胯部横线、浅色紧身下装

## 三、通用手法（穿哪个症状都用得上）

### 三分法
下摆、色块断点、腰线位置落在身高的 1/3 或 2/3 处，比落在 1/2 处顺眼。上衣下摆到胯（约 2/3）通常比到腰（约 1/2）更稳。

### 体积守恒
上宽下窄，或上窄下宽。上下都宽必须加收口（腰带、束脚、短款、合身内搭），否则整体变成盒子。

### 纵向线 = 拉长
竖条、开襟、V 领、同色系、裤中缝、长项链、长外套。用在想拉长的部位。

### 横向线 = 加宽
横条、船领、育克线、色块分割、口袋。用在想加宽的部位。

### 深色后退，浅色前进
想收敛的用深色，想强调的用浅色。这条比任何"显瘦穿搭"口诀都直接。

### 面料决定体积
- 减体积：垂坠（真丝、醋纤、莫代尔、斜裁、针织罗纹）
- 塑形：硬挺（丹宁、西装呢、塔夫绸、皮革）
- 想收的地方用垂坠，想撑的地方用硬挺。

### 图案
大图案放大、小碎花收敛、高对比图案抢视线。图案放在想让别人看的位置。

### 裤长与鞋
九分露踝最稳；全长盖鞋面拉长；鞋与裤/腿同色延长视觉。这三个动作几乎不挑体型。

## 四、多症状并存时怎么排序

用户往往同时有三四条。优先级：

1. **先定主视觉轴**（SHR 决定的肩胯关系）——它决定整体轮廓，其他都是局部
2. **再定腰线策略**（WHR 决定造腰还是顺直）
3. **再处理长度**（LBR 与 TBR 决定分割位置）
4. **最后是局部**（颈、胸、臂、腿、头肩比）

三条处方起步、五条封顶。超过五条用户执行不了，等于没给。

## 五、冲突调和

多个处方同时成立时，它们经常要动同一件单品、方向相反。排序只管先后，不管共存——这一节给共存的做法。

### 5.1 高频对冲对

| 冲突 | 撞在哪 | 解法 |
|---|---|---|
| 加宽肩部 ↔ 上下同色拉长 | 肩窄要上身浅色加宽，腿短要上下同色延长 | **明度递进**：浅上 → 中深下 → 最深鞋。不要用对冲（白上 + 黑下 + 白鞋），那会把身体切成两段 |
| 造腰 ↔ 拉长 | 宽腰封能造腰，但把躯干压短 | 用**位置**不用**宽度**：腰线抬 3–4cm、腰带 ≤2cm，不用宽腰封 |
| 下盘加体积 ↔ 收敛胯 | 肩宽要下装加体积，胯宽要下装收敛 | 体积加在**下摆**不在**胯部**：A 字从大腿中段起摆、直筒带微喇；避开胯部贴袋和硬挺横线 |
| 上身加体积 ↔ 减胸前体积 | 肩窄要上身有结构，胸大要减胸前堆料 | 体积加在**肩部**：薄垫肩、育克线、肩部拼接；胸前保持干净 |
| 短躯干 ↔ 长躯干 | 一个要抬高腰线、一个要下移 | 以躯干比为准，只有一条成立；躯干比不可读时，默认「不用宽腰封」，两边都不至于错太远 |
| 露踝拉长 ↔ 小腿粗 | 九分露踝能拉长，但露出小腿最粗处 | 踝口选在**脚踝最细处**（脚踝骨上方 2–3cm）；小腿粗改用及踝直筒或阔腿盖住，靠鞋裤同色拉长 |
| 高领显头小 ↔ 颈短要开领 | 头肩比大想加纵向体积，颈短要高领遮挡 | 领口开大 + 发型加横向体积，两个动作可以并存；必须二选一时选开领 |

### 5.2 三条原则

1. **加宽靠位置，不靠体积**——肩部加结构有效，胸前加堆料只是变胖。
2. **拉长靠连续，不靠统一**——明度递进、同色系、竖线，都算连续；不是必须一身一个颜色。
3. **两件单品争同一个动作时，选可逆的那个**——外套可脱、腰带可解、塞衣角可放，剪裁不可逆。

### 5.3 判断哪个方案优先

同一组数据可以出多个都成立的方案时，按「用户实际会穿」选，不按理论最优选：

- 用户每天要见客户 → 优先正装兼容性
- 用户说「不想穿高跟」→ 腿长处方改走同色系和裤长，不走鞋跟
- 用户衣柜现状不明 → 优先只换一件的方案

## 六、常见误判

- **把宽松衣服当成身材**：宽松上衣会让人误判肩宽与腰线。判读前先问"这张图里衣服是宽松还是贴身"。
- **把姿势当成骨架**：含胸会让肩显窄、塌腰会让腰线消失、踮脚会让腿显长。要求自然站姿。
- **把镜头当成比例**：手机近距离广角会把画面中心放大、边缘拉伸，腿显长、头显大。要求平视 + 后退。
- **把单一指标当结论**：WHR 高不代表"腰粗是缺点"，只代表"腰的视觉存在感弱"。处方是手法，不是评价。
