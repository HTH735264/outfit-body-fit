# 反馈回填

没有回填，这个 skill 只能不断给出一套推理正确但未经检验的建议。回填是把「推理」变成「证据」的唯一途径。

## 一、先拿授权

**默认不写本地文件。** 只有用户明确说「记住」「保存」「建个画像」「下次别再问我」这类意思时，才写入。

首次写入前用一句话确认：

> 我会把这组数据和这次的结果存到本地 `~/.outfit-body-fit/`，只存文字不存照片，你随时可以让我删。要存吗？

用户没明确同意 → **不写**，只在当前对话里用，并在结尾说明「这次没有保存」。

## 二、存在哪

用户主目录下，**不在仓库里**：

- Windows：`%USERPROFILE%\.outfit-body-fit\`
- macOS / Linux：`~/.outfit-body-fit/`

文中统一写 `~/.outfit-body-fit/`，执行时按当前系统展开。仓库 `.gitignore` 已排除 `.outfit-body-fit/` 和 `*.jsonl`。

## 三、两个文件

### profile.json（可选）

```json
{
  "measurements": {
    "height_cm": 170, "shoulder_width_cm": 36, "hip_width_cm": 38,
    "waist_cm": 72, "hip_cm": 94, "bust_cm": 87, "crotch_height_cm": 76
  },
  "computed": { "shr": 0.95, "whr": 0.77, "lbr": 0.45 },
  "constraints": { "no_heels": true, "budget": "中", "climate": "华东" },
  "known_good": ["正肩薄垫肩西装", "深灰直筒九分西裤"],
  "known_bad": ["插肩卫衣", "大摆伞裙"]
}
```

### feedback.jsonl（每行一条）

```json
{"date":"2026-11-11","scenario":"通勤-会议","prescriptions":["正肩+方领","明度递进"],"worn":"米白正肩西装 + 深灰直筒 + 黑乐福","verdict":"好","note":"肩线明显改善，裤长偏长","reuse":true}
```

| 字段 | 取值 |
|---|---|
| `verdict` | `好` / `中` / `差` |
| `reuse` | `true` / `false` |
| `note` | 一句话，≤30 字 |

`prescriptions` 写处方标签，不写整段话——后面统计靠它匹配。

## 四、写不进去怎么办

| 情况 | 处理 |
|---|---|
| 当前 Agent 没有文件读写能力 | 明说「本次只在当前对话生效，无法保存」，**不得假装已保存** |
| 目录不存在 | 先创建；创建失败按上一行处理 |
| 写入报错（权限、占用、磁盘满） | 报告失败原因，把内容贴在对话里让用户自己存，不重试超过一次 |
| JSON 文件损坏 / 解析失败 | 不覆盖原文件；提示「已有记录无法解析，要我先备份再重建吗」 |
| 多 Agent / 多会话并发写 | 只做**追加**（一行一条），不做整体重写；`profile.json` 更新时先读再改，冲突时以最新一次用户确认为准 |
| 用户要求删除 | 删除整个目录即可，不留备份，并回一句「已删除」 |

## 五、怎么用

**开场**：有 `profile.json` 就读，已知数据不再问；有 `feedback.jsonl` 就读最近 5 条。读不到就正常开场，不报错。

**调处方**：

- 同一处方连续 2 次 `差` → 这条对这个用户不成立，改走「冲突调和」里的备选，并说明改了什么
- 同一处方累计 3 次 `好` → 提为默认动作，不再解释原理
- 整套方案 `reuse: false` 多于 `true` → 整套降级，不原样复用

**写回**：用户回填后立刻追加一行，并更新 `known_good` / `known_bad`。不要攒着等下次。

## 六、边界

- 只存文字结论，**不存照片**
- 不回填用户没说过的信息（体重、年龄、身材评价）
- 对外分享这个 skill 时记录不会跟着走——它在用户自己机器上
- 用户说删就删，不留备份
