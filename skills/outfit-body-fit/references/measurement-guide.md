# 量体与输入核对

只收集会改变当前建议的数据。没有照片或数字时仍可根据用户自述给试穿方案；单件合身度不需要全套量体。

## 按需收集

| 想了解什么 | 需要什么 |
|---|---|
| 肩胯横向关系 | 肩宽、臀宽 |
| 腰臀围度差 | 腰围、臀围 |
| 胸腰围度差 | 胸围、腰围 |
| 会阴高度占身高比例 | 会阴高、身高 |
| 肩峰到腰线的垂直占比 | 肩峰高、腰高、身高 |
| 头肩横向对比 | 头宽、肩宽 |

肩宽、臀宽、腰围、臀围、身高是一个常用基础组合，不是开始给建议的门槛。给了部分数据就计算已满足输入条件的项目。

## 测量口径

用软尺测围度，用直尺或他人帮助测直线宽度；不把衣服平铺尺寸当身体尺寸。自然站立，不故意挺胸、收腹或踮脚，围度软尺保持水平、贴合不勒。尽量保持测量时间、衣着与姿势一致。

| 字段 | 口径与注意事项 |
|---|---|
| 肩宽 | 左右肩峰点间的直线距离，不是沿背部走弧线，也不是衣服肩缝间距；自己难定位时请人协助 |
| 臀宽 | 臀部最宽处左右两侧的水平直线距离，不是绕一圈，不由臀围除以固定常数推算 |
| 腰围 | 躯干自然腰线的一周，正常呼吸、不收腹；自然腰线不明显时记录实际量的位置，复测保持同一位置 |
| 臀围 | 臀部最丰满处水平一周 |
| 身高 | 脱鞋，平地直立、平视、脚跟落地，从头顶量到地面，不强迫身体各部位都贴墙 |
| 胸围 | 胸部最丰满处水平一周，记录衣着条件以便复测；不需要提供内衣尺码 |
| 腰高 | 与本次腰围同一个水平面到地面的垂直距离，不是裤子的腰头高度 |
| 会阴高 | 站立时裆部接触平面到地面的垂直距离，可用平直书本水平轻触裆部、在墙上标高度再量；不适或不愿测就跳过，不用裤内长替代 |
| 肩峰高 | 肩峰点到地面的垂直距离，和腰高使用相同站姿 |
| 头宽 | 头部左右最宽处的直线距离，尽量不含头发体积；难测时跳过，不必为穿搭强行测齐 |

贴墙或辅助物只能帮助取点，不把墙上照片的像素当厘米。量两次差异明显时先检查取点、软尺水平和姿势，再复测；不要用平均数掩盖不同测量口径。

## 先查结构错误

1. 所有输入必须为有限正数。零、负数、空值或非数字使相关指标不可计算，不影响其他项目。
2. 已提供的高度应满足：会阴高、腰高、肩峰高都小于身高，且肩峰高大于腰高。矛盾时问相关两项的量法，不替用户改数。
3. “臀宽94”同时“臀围94”等疑似字段混淆时，确认分别是直线宽度还是环绕围度。
4. 用户已说明量的是衣服肩线、裤内长或裤腰位置时，保留为衣服数据，不代入对应身体公式。
5. 围度差较大或比例少见，本身不证明量错。不设“合理身材区间”，不要求用户为范围外的真实数据解释体型、健康或性别。

确认量法后，接受有效测量并保留来源。若仍不确定，将受影响项目标“口径待确认”，其余照常计算。用户不想复测时，改给不依赖该项目的试穿方案。

## 单位和字段歧义

| 输入 | 处理 |
|---|---|
| 明确cm、厘米 | 原值使用 |
| 明确in、英寸 | ×2.54，复述换算值，可继续计算 |
| 明确m、米 | ×100 |
| “身高1.70” | 身高语境清楚时说明按1.70米即170厘米处理；若字段含糊则确认 |
| 市尺、市寸 | 明确是中国市制时按1尺=100/3厘米、1寸=10/3厘米 |
| 只有“尺/寸” | 先确认市制、英制或其他口径 |
| “34-24-34” | 确认是否胸腰臀及单位，不能仅因三个数就默认英寸 |
| “1,70” | 根据字段与上下文确认是否小数逗号；不能对所有逗号数据都按米处理 |
| “36/38/72/94”且无字段 | 请用户注明各数对应的项目 |

没有单位但语境是中文人体厘米量体时，可说明默认按厘米处理；数值形式或量法有歧义时先确认。

## 误差与展示

- 以未舍入数值计算、比较分界，展示通常保留两位小数，不先将76/170舍入成0.45再分组。
- 测量重复值跨过经验分界时，写“接近分界，暂不分组”，给试穿比较；不声称达到厘米级造型精度。
- TBR仅说明肩峰到腰线的垂直占比，无通用“长/短”分界，也不能推出固定上衣长度。
- 胸腰差只能描述两个围度的差，不能确认胸部大小。
- 同一个人不同时期的数据冲突时，询问采用哪组；不把旧画像静默覆盖本次输入。
