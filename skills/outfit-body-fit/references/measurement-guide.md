# 自助量体

## 一、需要什么

一条软尺、一面墙、一面能看全身的镜子。没有软尺：用无弹性的绳子绕一圈做记号，再用直尺量绳长；或者去裁缝店/改衣店，通常免费或很便宜。

## 二、最小集（四个数就够）

### 肩宽
背后站直，双臂自然下垂。找人帮你量**左右肩峰点**之间的直线距离——就是肩头那两个骨头尖，不是肩关节、不是衣服的肩线、不是沿着肩斜的弧线。
自己量：贴墙站，在两侧肩峰点各贴一张便签，退开量两张纸之间的距离。

### 腰围
找到躯干最细处（通常在肋骨下缘和胯骨上缘之间），软尺水平绕一圈，贴皮肤不勒紧。**正常呼气末测，不要吸肚子**。早上空腹测最稳定。

### 臀围
臀部最丰满处水平绕一圈。软尺保持水平，不要斜着往下掉。

### 身高
脱鞋，脚跟、臀、肩胛、后脑贴墙。

## 三、加分集（想把结论做准就补这三个）

### 胸围
胸部最丰满处水平绕一圈，软尺经过肩胛骨下角。穿薄内衣测。

### 腰高
腰围最细处那个水平面，到地面的垂直距离。贴墙站，在墙上标记腰线高度，退开量到地面。

### 会阴高
站直、双脚并拢，耻骨联合下缘（裆部最上端）到地面。这个数直接决定腿长比。

## 四、常见量错

| 错误 | 后果 |
|---|---|
| 肩宽量成衣服肩线 | 通常偏大 2–4cm，SHR 直接反向 |
| 肩宽量成肩关节（更靠内） | 偏小 2–3cm |
| 腰围吸肚子 | 偏小 3–6cm，WHR 虚低 |
| 腰围量在裤腰位置 | 那是低腰，不是自然腰，偏大 |
| 臀围斜着量 | 偏大 |
| 穿厚衣服量 | 全部偏大 |
| 只量一次 | 误差无法发现，建议连量两次取平均 |

## 五、口径自查

量完做两个 sanity check：

1. 肩宽 − 臀宽：女性常见区间里两者接近；如果算出来差 8cm 以上，八成是肩宽量成了衣服肩线或量到了肩关节外侧。
2. 腰围 ÷ 臀围：落在 0.65–0.95 之外，重测。

## 六、不想量怎么办

直接走照片通道，输出会标注「视觉印象，非测量结论」。不要劝。但如果用户反复追问「准不准」，说明一次：照片判断方向没问题，判断幅度会错，四个数就能补上。
