# 自助量体

## 一、需要什么

一条软尺、一面墙、一面能看全身的镜子。没有软尺：用无弹性的绳子绕一圈做记号，再用直尺量绳长；或者去裁缝店/改衣店，通常免费或很便宜。

## 二、最小集（四个数就够）

### 肩宽
背后站直，双臂自然下垂。找人帮你量**左右肩峰点**之间的直线距离——就是肩头那两个骨头尖，不是肩关节、不是衣服的肩线、不是沿着肩斜的弧线。
自己量：贴墙站，在两侧肩峰点各贴一张便签，退开量两张纸之间的距离。

### 腰围
找到躯干最细处（通常在肋骨下缘和胯骨上缘之间），软尺水平绕一圈，贴皮肤不勒紧。**正常呼气末测，不要吸肚子**。早上空腹测最稳定。

### 臀围
臀部最丰满处水平绕一圈。软尺保持水平，不要斜着往下掉。

### 身高
脱鞋，脚跟、臀、肩胛、后脑贴墙。

## 三、加分集（想把结论做准就补这三个）

### 胸围
胸部最丰满处水平绕一圈，软尺经过肩胛骨下角。穿薄内衣测。

### 腰高
腰围最细处那个水平面，到地面的垂直距离。贴墙站，在墙上标记腰线高度，退开量到地面。

### 会阴高
站直、双脚并拢，耻骨联合下缘（裆部最上端）到地面。这个数直接决定腿长比。

## 四、常见量错

| 错误 | 后果 |
|---|---|
| 肩宽量成衣服肩线 | 通常偏大 2–4cm，SHR 直接反向 |
| 肩宽量成肩关节（更靠内） | 偏小 2–3cm |
| 腰围吸肚子 | 偏小 3–6cm，WHR 虚低 |
| 腰围量在裤腰位置 | 那是低腰，不是自然腰，偏大 |
| 臀围斜着量 | 偏大 |
| 穿厚衣服量 | 全部偏大 |
| 只量一次 | 误差无法发现，建议连量两次取平均 |

## 五、口径自查

量完做两个 sanity check：

1. 肩宽 − 臀宽：女性常见区间里两者接近；如果算出来差 8cm 以上，八成是肩宽量成了衣服肩线或量到了肩关节外侧。
2. 腰围 ÷ 臀围：落在 0.65–0.95 之外，重测。

## 六、单项绝对值复核

口径自查只查相对关系（差多少、比值多少），查不出**单项绝对值本身不合理**。差 3cm 能通过相对检查，但 170 的个子报 44cm 臀宽就可能量错了——比值 0.259，已经超出 0.20–0.23。

输入数据先过一遍这张表，超范围不要直接改数，而是问一句「这个是怎么量的」。

| 项目 | 合理区间 | 超范围时最可能的原因 |
|---|---|---|
| 肩宽 | 女 34–41cm，男 40–48cm | 量成衣服肩线（偏大）或肩关节内侧（偏小） |
| 臀宽 ÷ 身高 | 0.20–0.23 | 量成围度（大得离谱）或量在胯骨上缘（偏小） |
| 腰围 ÷ 身高 | 0.40–0.50 | 吸肚子（偏小）或量在裤腰位置（偏大） |
| 臀围 ÷ 臀宽 | 2.2–3.0 | 两者有一个量错；小于 2.2 多半臀宽量成围度 |
| 会阴高 ÷ 身高 | 0.42–0.49 | 量到裆部外端（偏大）或坐着量的（偏小） |
| 头宽 | 13–16cm | 量成头长 |

### 为什么用比值不用绝对数

158 和 175 的合理臀宽不是一个数。用「臀宽 ÷ 身高」才能同时覆盖不同身高，而且这个比值对量错极其敏感——臀宽误量成半围度，比值会从 0.22 跳到 0.30 以上。

### 触发后怎么处理

1. 指出哪一项超范围、超了多少
2. 说清这个误差会把哪个指标带偏、偏多少（例：臀宽若误量，肩臀比会从 0.95 变成 0.39，结论反向）
3. 让用户复核，**不要替用户改数**
4. 在结论里把受影响的指标标「待确认」，其余指标照常给

## 七、不想量怎么办

直接走照片通道，输出会标注「视觉印象，非测量结论」。不要劝。但如果用户反复追问「准不准」，说明一次：照片判断方向没问题，判断幅度会错，四个数就能补上。
