# 量体穿搭：按身材比例给方案

把「我这个身材适合穿什么」拆成可执行的比例判读 + 版型处方。核心不是身材标签，是**你想在视觉上把重量放在哪**。

## 两个输入通道（分工不同，不是互不相关）

| 通道 | 输入 | 职责 | 能产出 | 数据完整度 |
|---|---|---|---|---|
| A 照片 | 全身 / 半身照 | 定**方向** | 视觉轮廓走向、肩胯相对关系、上下身分割位置、姿态习惯 | 中 / 低 |
| B 数字 | 见下方字段定义 | 定**幅度** | 可算的比例指标 | 高 |

**照片定方向，数字定幅度。** 照片用来发现视觉走向，也用来检查服装、姿势、拍摄造成的偏差；数字用来算比值。两者冲突时以数字为准，并说明照片里哪个动作造成了偏差。

绝不用照片反推围度、身高或体重。绝不给「你应该是 X 型身材」的确定结论。

### 字段定义（宽度和围度不能混用）

| 字段 | 类型 | 定义 |
|---|---|---|
| 肩宽 | 直线**宽度**（cm） | 左右肩峰点之间的距离 |
| 臀宽 | 直线**宽度**（cm） | 臀部最丰满处两侧的水平直线距离 |
| 腰围 | 环绕**围度**（cm） | 躯干最细处一周 |
| 臀围 | 环绕**围度**（cm） | 臀部最丰满处一周 |

**肩臀比只能由「肩宽 ÷ 臀宽」得出，腰臀比只能由「腰围 ÷ 臀围」得出。** 只有臀围时，肩臀比一律判为不可读——两者不是同一个量，换算不成立。

## 工作流

### 第 0 步：定档位

| 档 | 输入 | 能算的指标 | 数据完整度 |
|---|---|---|---|
| A | 只有照片 | 0，只给视觉方向 | 低 |
| B− | 至少一项有效数字，但未齐 | 已有的局部指标照算，但**不做完整主视觉轴判定** | 中 |
| B | 肩宽、臀宽、腰围、臀围、身高 齐全 | 肩臀比、腰臀比 | 高 |
| B+ | B 再加胸围、腰高、会阴高、头宽、肩峰高 | 再加胸腰差、腿长比、躯干比、头肩比 | 高 |

**B− 不是「什么都不能算」。** 有胸围和腰围就能算胸腰差，有肩宽和臀宽就能算肩臀比。缺的是**定主视觉轴所需的完整组合**，所以不做整体轮廓判定，但能算的局部指标照常算，各自给方向。

四条规则：

1. **B 档必须齐五个数**：肩宽、臀宽、腰围、臀围、身高。缺臀宽 → 肩臀比不可读，整体停在 B−
2. 缺哪个指标就标哪个「不可读」，不用相近指标替代，也不猜
3. 照片和数字都有 → 走数字档，照片做交叉校验
4. **数字优先**：照片造成的「不可读」只作用于照片通道，不覆盖已有的实测值。某指标有数字就直接算，即使照片里读不到；反过来，照片读得到但数字缺失时，也不能把目测值当成实测值写进判读表

**「数据完整度」不等于「判断准确度」。** 表里的档位只描述输入齐不齐——B 档是「数据够算」，不是「结论经过验证」。输出时要分开写：

- 数据完整度：高 / 中 / 低（取决于五个数齐不齐）
- 判断置信度：中到高（上限在这里，因为规则本身是经验性视觉判断，不是测量学结论）

不要只写一个「置信度：高」，那会被读成「科学准确」。

### 第 0.5 步：先看照片被修过没有

照片里的比例经常已经被服装和拍摄改过一轮。跳过这一步，后面所有判读都在读一个加工过的结果，而且会读得很有说服力。

按影响**分三级**，不是一律报警：

| 等级 | 触发 | 处置 |
|---|---|---|
| 轻 | 只命中常规穿着：普通有跟鞋、常规裤装、路边自然站姿 | 输出末尾一句话带过，不占篇幅 |
| 中 | 修正改变了某个关键指标：宽松外套遮腰、手插口袋压肩线、手机挡脸、双脚被裁、明显仰拍或俯拍 | 该指标标「**不可读**」，其余照常判读 |
| 重 | 图像本身不可信：AI 生成水印、明显拉伸或修图、商用精修模特图 | **停止比例判读**，只给版型与搭配建议 |

中、重两级必须在输出开头写明命中了哪几条，声明句固定用：「以下判断的是照片中呈现的比例，不是原始骨架」。

完整清单与话术见 [references/photo-reading.md](references/photo-reading.md)。

### 第 1 步：收数据

B 档最小集是五个数：**肩宽、臀宽、腰围、臀围、身高**。别一次抛八个字段，按这个顺序问：

1. 肩宽、臀宽、腰围、臀围、身高
2. 够不够 → 再要胸围（胸腰差）、会阴高（腿长比）
3. 用户不想量 → 进 A 档，别劝

**输入规范**：

- 默认单位厘米。看到英寸 ×2.54、看到米 ×100，换算后**复述一遍**确认，不要直接算
- 「肩宽」若说的是衣服肩线或肩关节内侧，重问口径；这两个会偏 2–4cm，足以让肩臀比反向
- 臀围当臀宽报（数值明显过大）→ 指出并重问，不修正、不换算
- 数值明显异常时先问怎么量的，见 [references/measurement-guide.md](references/measurement-guide.md) 的复核表

### 第 2 步：判读

| 指标 | 公式 | 最小输入 | 经验分界 | 不可计算条件 |
|---|---|---|---|---|
| 肩臀比 | 肩宽 ÷ 臀宽 | 肩宽、臀宽 | ≥1.04 肩宽于胯 ｜ ≤0.96 肩窄于胯 | 缺臀宽；臀宽 ≈ 0；只有臀围 |
| 腰臀比 | 腰围 ÷ 臀围 | 腰围、臀围 | <0.75 腰线明确 ｜ >0.85 腰线弱 | 缺其一；臀围 ≈ 0 |
| 胸腰差 | 胸围 − 腰围 | 胸围、腰围 | ≥18cm 起伏明显 ｜ <10cm 偏平直 | 缺其一 |
| 腿长比 | 会阴高 ÷ 身高 | 会阴高、身高 | <0.45 偏短 ｜ >0.48 偏长 | 会阴高 > 身高 |
| 躯干比 | (肩峰高 − 腰高) ÷ 身高 | 肩峰高、腰高、身高 | **数值越大 = 躯干越长** | 肩峰高 ≤ 腰高 |
| 头肩比 | 头宽 ÷ 肩宽 | 头宽、肩宽 | >0.40 头在视觉上偏大 | 缺其一 |

**关于这些分界**：它们是**穿衣视觉分析的经验值，不是医学或人体测量标准**。来源是形象造型实践，不是人体测量学样本。数值落在边界附近（如 0.97–1.03）时只写「接近均衡」，不强行归类。

**指标优先级**（能算几个先算前几个）：肩臀比 > 腰臀比 > 腿长比 > 胸腰差 > 躯干比 > 头肩比。

**不可读的写法**：缺数据写「不可读」并说明缺什么。例：「肩臀比：不可读（缺臀宽，只有臀围）」。

判读写成**比例特征 + 视觉后果**，不写身材类型名。例：「肩臀比 0.95 → 肩线比胯线窄，视觉重量偏下」。

### 第 3 步：开处方

三条起步，按视觉影响从大到小排。每条必须是「手法 + 具体单品动作 + 为什么」。

高频六条（完整版见 [references/proportion-rules.md](references/proportion-rules.md)）：

- **肩窄于胯** → 抬高肩线：正肩结构、薄垫肩、船领/方领、上身浅色横条；下装深色直筒微锥；避开插肩袖、落肩
- **肩宽于胯** → 弱化肩端点：插肩/落肩、V 领把视线收到中间、上身深色无肩部装饰；下装加体积
- **腰线视觉存在感弱** → ① 做结构（收腰剪裁、塞衣角、上下色块在腰处分界）；② 顺直筒（H 型 + 垂坠面料）。避开紧身针织
- **腿部占比偏小** → 高腰、上下同色系、短上衣、露踝、鞋裤同色；避开中筒靴
- **头在视觉上偏大** → 加肩宽 + 发型加横向体积；避开紧贴头皮与高领
- **胸前横向体积明显** → V 领、垂坠面料、收腰；避开高领、胸前大图案、硬挺 boxy

### 第 4 步：出搭配

两套完整方案，覆盖用户实际场景（没给场景就用「日常通勤」+「周末」）。每套写清：上装 / 下装 / 鞋 / 外层 / 一句话说明为什么对着他的比例有效。

不要堆单名清单，不要列十个品牌。

### 第 5 步：自检

- [ ] 照片影响等级是哪一级？中/重是否写明命中条目，被抹掉的指标是否标「不可读」？
- [ ] 字段有没有混淆宽度的和围度的？肩臀比是不是用臀宽算的？
- [ ] 有没有把照片读数写成了测量结论？
- [ ] 有没有把体型标签复述成结论？
- [ ] 每条处方是否带「为什么」？
- [ ] 有没有出现身体部位的评价词（胸大/腿粗/胯宽这类）？
- [ ] 有没有出现体重、减重、医美、好坏评价？
- [ ] 数据完整度与判断置信度有没有分开写？目测值和实测值有没有混在一起？
- [ ] 单位与口径是否确认过？

### 第 6 步：回填（需用户同意）

方案给完，末尾附一行：

> 穿完回一句就够：`好 / 中 / 差 + 一句话`

**只有用户明确说「记住」「保存」或同意建立画像时才写入本地文件**，默认不自动存。写入位置与失败处理见 [references/feedback-loop.md](references/feedback-loop.md)。

同一处方连续 2 次「差」→ 改走「冲突调和」里的备选，并说明改了什么。用户不回就结束，不追问第二次。

## 硬性边界

- 不评价体重、不推荐减重、不评价长相、不建议医美。用户问「我是不是太胖」→ 转成「穿衣能改的是视觉比例，体重不是这个 skill 的输入」
- **不用身体部位的评价词**。写「胸前横向体积明显」，不写「胸大」；写「小腿横向体积明显」，不写「小腿粗」
- 用户表达身材焦虑时先接住情绪，再给可控的部分，不强化「遮」「藏」「遮丑」这类叙述
- 用户说明自己是未成年人 → 只给合身度、场合、舒适度建议
- 不推测健康状况、年龄、生育情况、职业收入
- 涉及内衣尺码、束身衣、矫正带 → 不提供

## 规则来源与边界

- **理论来源**：AICI 形象顾问课程、FIT 个人造型课程、《What Not to Wear》(Trinny Woodall & Susannah Constantine, 2002) 的比例方法论；结构化参考 [jeffreytse/grimoire-core](https://github.com/jeffreytse/grimoire-core)（MIT）
- **本 skill 自设的启发式**：全部具体数值分界（1.04 / 0.96 / 0.75 / 0.85 / 18cm / 0.45 / 0.48 / 0.40）、三级影响分级、冲突调和的七组解法。这些是按造型实践归纳的经验值，**没有对上述资料做过逐条核对，也不是人体测量学结论**
- **个体规则**：用户反馈累积出来的调整，只对那个用户成立
