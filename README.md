# 量体穿搭 · outfit-body-fit

根据用户的视觉目标、测量数据或穿着照片，给出能试穿比较的版型与搭配建议，也可检查单件合身度。

## 怎么使用

- **有数字**：逐项计算已满足输入条件的指标，说明依据和限制，不要求先量齐全身。
- **有照片**：描述看得到的服装轮廓，考虑遮挡与透视，不反推厘米或把目测值放进数字表。
- **只有自述**：按场景、风格和活动需求给方案，无需先上传照片。
- **只问一件衣服**：直接看合身度和可调整动作。
- **参考图经过编辑或生成**：拆版型、色彩与分割线，不把图中比例当用户的身体。

视觉目标由用户决定。肩部更明显、保留宽松轮廓、不强调腰线都可以；不默认所有人都要同一套肩胯比例。

## 输入与判断

肩宽、臀宽是直线宽度，腰围、臀围是环绕围度。肩臀比需要肩宽和臀宽；腰臀比需要腰围和臀围，两者不能换算。

支持肩臀比、腰臀比、胸腰差、腿长比、躯干比、头肩比。各自有数据才计算。数值分界属于本仓库经验线索，未作人群验证；躯干比没有通用长短分界，只解释连续数值。量体完整程度不等于造型效果准确度。

输出通常包含1–3个有依据的动作，需要整套时再给1–2套。每个动作说明如何穿、预期效果及试穿看什么，不输出永久禁穿清单。

## 示例

```text
我身高170厘米，肩宽36、臀宽38、腰围72、臀围94、会阴高76。
通勤想让肩部更利落，不穿高跟鞋，有深灰长裤和乐福鞋，怎么搭？
```

```text
肩宽40、臀宽38厘米，想强调肩部，腰围不想量。给我一个先试的办法。
```

```text
我不想量体。周末走路多，喜欢宽松，只穿裤子和平底鞋，帮我搭一套。
```

## 安装

```bash
npx -y skills add HTH735264/outfit-body-fit -g --all
```

指定Agent示例：

```bash
npx -y skills add HTH735264/outfit-body-fit -g -a claude
```

手动安装：复制`skills/outfit-body-fit/`整个目录到Agent的skills目录，如`~/.agents/skills/`、`~/.claude/skills/`或`~/.codex/skills/`。

## 可选记忆与边界

默认只在当前对话中使用反馈。用户明确要求保存时才在授权范围内持久化，成功后说明实际路径；没有文件能力时如实说明。只保存必要文字与数值，不存照片，不把别人或示例人物的数据混进用户画像。

不评价身体好坏，不建议减重、医美或身体矫正；不推测健康、年龄或生育情况。用户说明是未成年人时，只给场合、舒适度和合身度建议。
