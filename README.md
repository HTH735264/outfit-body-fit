# 量体穿搭 · outfit-body-fit

一个按**身材比例**给穿搭方案的 Agent Skill。不给你贴身材标签，给你可执行的版型处方。

## 它解决什么

「我这个身材适合穿什么」这句问题，绝大多数穿搭回答都在做两件事：贴标签（你是梨形 / 苹果形）和堆单品清单。前者把比例问题说成人身属性，后者不可复用——换一件衣服你就又不会了。

这个 Skill 换了个拆法：把身材拆成六个可计算的**比例指标**，每个指标对应一组**版型手法**，每条手法带「为什么」。学到的是判断方法，不是一份清单。

## 怎么工作

两个输入通道，严格不混用：

| 通道 | 输入 | 能产出 | 置信度 |
|---|---|---|---|
| A 照片 | 全身 / 半身照 | 视觉轮廓走向、肩胯相对关系、上下身分割位置、头肩比 | 中 / 低 |
| B 数字 | 肩宽、胸围、腰围、臀围、身高、腰高、会阴高 | 可算的比例指标与幅度 | 高 |

**照片定方向，数字定幅度。**

照片不做测量。手机广角会把画面中心放大、边缘拉伸，俯拍压短腿、仰拍拉长腿，宽松上衣会让腰线位置完全失真——用照片反推围度是错的。所以只有照片时，输出会明确标注「视觉印象，非测量结论」，并告诉用户补哪几个数就能升级精度。

六个指标：肩臀比、腰臀比、胸腰差、腿长比、躯干比、头肩比。每个指标映射到一组处方，完整表在 [`references/proportion-rules.md`](skills/outfit-body-fit/references/proportion-rules.md)。

## 安装

```bash
npx -y skills add HTH735264/outfit-body-fit -g --all
```

装到指定 agent：

```bash
npx -y skills add HTH735264/outfit-body-fit -g -a claude
```

手动安装：把 `skills/outfit-body-fit/` 整个目录复制到 agent 的 skills 目录（如 `~/.agents/skills/`、`~/.claude/skills/`、`~/.codex/skills/`）。

## 最短示例

```text
我 162，肩宽 37，臀宽 40，腰围 74，臀围 96，胸围 88，会阴高 72。平时通勤穿什么？
```

输出会是一张指标判读表、三条按影响排序的处方（每条带「为什么」）、两套完整搭配、一份雷区清单，以及置信度和待补数据。

只有一张照片时，把照片丢过去直接问「我这个身材怎么穿」即可，Skill 会走 A 档并主动降级标注。

## 边界

**做**：比例判读、版型处方、成套搭配、雷区、合身度判断（针对已穿的衣服）。

**不做**：

- 不评价体重、不推荐减重、不评价长相、不建议医美
- 不问内衣尺码、束身衣、矫正带
- 不推测健康状况、年龄、生育情况
- 用户说明是未成年人时，只给合身度与场合建议，不做身材判读
- 不推测身材类型标签当结论

用户表达身材焦虑时，先接住情绪，再给可控的部分：比例、版型、颜色。

## 更新记录

### v1.1.0

新增**照片修正检查**（`SKILL.md` 第 0.5 步）。这一版修的是可信度问题，不是精度问题。

背景：测试时发现，穿搭照里的比例经常已经被服装和拍摄改过一轮——高腰裤抬腰线、仰拍拉长腿、落肩削肩宽、手插口袋压肩线。原流程会按图老实判读，但读到的是加工后的结果，并且读得很有说服力，让人误以为「这个人本来就长这样」。

现在遇到以下情况会先声明，再判读：

- **服装类**：高腰、短上衣、宽松外套、垫肩/泡泡袖、高跟厚底、深色紧身下装、阔腿微喇
- **拍摄类**：仰拍、俯拍、广角近距离、镜面自拍、踮脚扭胯、手插口袋
- **图像类**：AI 生成水印、皮肤过度平滑、反射不自然、商用模特图

关键信息被抹掉的指标改为写「不可读」，不再猜一个值填上——宽松上衣遮腰就不判腰臀比，手机挡脸就不判头肩比。
